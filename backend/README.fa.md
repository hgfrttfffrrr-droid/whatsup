
# بک‌اند پیام‌رسان گپروم (GAPROM)

این پروژه شامل بک‌اند اولیه احراز هویت پیامکی با Node.js و PostgreSQL است.

## امکانات فعلی
- ثبت‌نام و ورود با شماره موبایل
- درخواست کد OTP
- تأیید کد پیامکی
- ساخت حساب کاربری
- صدور JWT
- ذخیره اطلاعات در PostgreSQL

## ساختار پروژه

- src/server.js : سرور API
- src/auth.js : احراز هویت و OTP
- src/db.js : اتصال دیتابیس
- package.json : وابستگی‌ها
- docker-compose.yml : تنظیمات PostgreSQL
- .env.example : نمونه تنظیمات محیطی

## راه‌اندازی

1. Node.js نسخه 18 یا بالاتر نصب شود.
2. PostgreSQL راه‌اندازی شود.
3. از فایل .env.example یک کپی با نام .env ساخته شود.
4. مقادیر اتصال دیتابیس و کلیدهای امنیتی تنظیم شوند.
5. دستور npm install اجرا شود.
6. دستور npm start اجرا شود.

## مسیرهای API

GET /health

POST /auth/request-otp

POST /auth/verify-otp

## نکات امنیتی

- کلید ملی پیامک فقط روی سرور قرار بگیرد.
- فایل .env هرگز در GitHub منتشر نشود.
- قبل از انتشار عمومی، API ملی پیامک باید آزمایش شود.

## وضعیت توسعه

این نسخه فقط بک‌اند اولیه ورود پیامکی است و هنوز به اپ Flutter متصل نشده است.

امکانات چت، گروه، ارسال فایل، استوری و WebSocket در مراحل بعدی توسعه داده خواهند شد.
